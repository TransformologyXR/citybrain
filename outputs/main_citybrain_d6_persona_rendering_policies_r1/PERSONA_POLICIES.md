# Persona Policies

Track P is packaging and narrative only. It packages a bounded local/replay Hero Neighbourhood control-room reference demo for review/query context. It does not claim production readiness, public API readiness, live monitoring, autonomous incident detection, alert push, dispatch, routing/control, enforcement, official ticket/case creation, legal/certified incident findings, a citywide certified twin, physical accuracy, or automated action.

## Executive

Concise outcome/status summary for a reviewer or sponsor.

- what is proven
- what remains limited
- bounded local/replay status

## Operator

Packet-oriented review view for inspecting the same frozen evidence.

- operator-surface packets
- affected entities
- overlays
- unresolved/quarantined contexts

## Planner

Spatial/contextual implications and scenario/corridor interpretation.

- Omniverse handoff
- graph/edge context
- scene-bound corridor framing

## Analyst

Evidence refs, limitation refs, validation/audit state, and compatibility notes.

- manifest rows
- evidence/limitation trace
- audit statuses
- non-blocking gaps
