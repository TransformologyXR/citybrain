# Boundary Policy

This package is only allowed to create a local/replay product-consumption layer from already accepted synthetic factory seeds.

## Allowed

- Combine synthetic/replay WATCH, ASK, CHECK, BRIEF, SPATIAL, and Event Fabric fixtures.
- Create D5 local served runtime packet fixtures.
- Create a D6 local static open index.
- Label LTA/TfL/OPSD as donor/context only.
- Label Overture/OSM/Microsoft-derived geometry as non-official seed geometry.

## Forbidden

- No live monitoring claim.
- No dispatch, routing, control, enforcement, legal, or certified claim.
- No official Dubai truth claim.
- No raw provider payload packaging.
- No credentials or provider keys in outputs.
- No human/person-level records.
- No mutation of Seed R1, Seed R2, R2E, R2B, R2A, or R2.
