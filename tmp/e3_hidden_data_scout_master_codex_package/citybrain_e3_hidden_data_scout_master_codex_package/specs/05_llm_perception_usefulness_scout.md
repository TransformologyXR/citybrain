# Lane E — LLM Seat + Perception Usefulness Scout

Scout usefulness metrics for LLM seats and perception/candidate observation flows.

## LLM metrics

- acceptance rate
- fallback rate
- unsafe proposal count
- schema failure count
- CHECK rejection count
- unsupported claim count
- latency/cost where available

## Perception metrics

- candidate observations
- clip/frame refs
- camera/source refs
- candidate review outcomes
- privacy/retention readiness
- packaged media presence
- source-class separation

Perception remains candidate-only.
