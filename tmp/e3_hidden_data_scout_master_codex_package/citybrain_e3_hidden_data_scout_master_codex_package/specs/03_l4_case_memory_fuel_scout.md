# Lane C — L4 Case Memory Fuel Scout

Find artifacts that can become non-predictive case memory.

## Candidate fields

- subject/entity refs
- source_class refs
- outcome lineage
- review state
- computed-match fields
- location/time
- domain family
- what was claimed / refused / cannot-claimed

## Do not infer outcomes

If an artifact has no explicit outcome/disposition/review-state, mark it `outcome_lineage_missing`.
