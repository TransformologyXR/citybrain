# Master scout contract

A hidden-data scout is a bounded repository/artifact-root investigation that identifies unmaterialized signals useful for Epoch 3 loops or broader CityBrain intelligence.

## Required candidate fields

- candidate_id
- candidate_family
- scout_lane
- source_roots
- source_refs
- source_class
- city
- domain_pack
- temporal_fields_present
- lineage_strength
- labelability_or_usefulness_rating
- promotion_status
- recommended_follow_on
- limitations

## Promotion status values

- candidate_inventory_only
- governed_label_rows_exist
- governed_case_rows_exist
- descriptive_metrics_only
- materialization_recommended
- blocked_missing_lineage
- blocked_policy
- blocked_not_enough_history
