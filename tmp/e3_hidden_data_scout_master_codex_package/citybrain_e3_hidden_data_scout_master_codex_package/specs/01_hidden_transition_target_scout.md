# Lane A — Hidden Transition Target Scout

Find dated lifecycle transitions beyond permit-stall.

## Required outputs

- `E3_HIDDEN_TRANSITION_TARGET_CATALOG.json`
- `E3_HIDDEN_TRANSITION_TARGET_SCOUT_REPORT.json`

## Candidate target rating

Use:

```text
A = immediate materialization candidate
B = plausible but needs label definition
C = data exists but censoring/lineage complex
D = descriptive only
E = insufficient transition evidence
```

## Mandatory checks

- transition source refs present
- at least one event/state date
- terminal outcome definition possible
- censoring policy possible
- city/domain-pack stats
- no single-snapshot conversion
