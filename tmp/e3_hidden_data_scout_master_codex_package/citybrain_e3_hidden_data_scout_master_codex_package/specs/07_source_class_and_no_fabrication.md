# Source-class and no-fabrication rules

No scout may fabricate lifecycle transitions, outcomes, review decisions, or source lineage.

## Forbidden conversions

- current snapshot → dated transition
- selected item → disposition
- candidate observation → confirmed fact
- LLM narrative → source fact
- proximity relationship → affected truth
- synthetic scenario → training fuel

## Allowed

- candidate inventory
- descriptive counts
- materialization recommendation
- governed rows only when source refs and lineage already support them
