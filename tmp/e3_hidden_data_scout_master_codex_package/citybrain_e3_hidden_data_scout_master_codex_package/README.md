# MAIN-CITYBRAIN-EPOCH3-HIDDEN-DATA-SCOUT-MASTER-R1

Codex package for a broad Epoch 3 hidden-data scout pass.

This is one parent package with five initial scout lanes plus a Track 0/global inventory rider. It starts with the five recommended scouts, but it must also inventory all discovered artifact roots and publish a follow-on backlog for every additional hidden-fuel/intelligence dimension found.

Expected closeout:

```text
PASS_E3_HIDDEN_DATA_SCOUT_MASTER_R1_WITH_LIMITATIONS
```

## Purpose

Find buried, unmaterialized evidence/fuel already present in CityBrain outputs, manifests, source records, run envelopes, decisions, reports, and fixtures before concluding that a loop is blocked by missing data.

This package is a scout package, not a model package and not a training package.

## Initial lanes

1. Lane A — Hidden Transition Target Scout
2. Lane B — CHECK Calibration Fuel Scout
3. Lane C — L4 Case Memory Fuel Scout
4. Lane D — Identity / Graph Evaluation Fuel Scout
5. Lane E — LLM Seat + Perception Usefulness Scout
6. Track 0 rider — Global hidden-data inventory, backlog, no-model guard, corpus delta, hash/LF

## Major invariant

No scout output may become training fuel by implication. Scout outputs are candidate inventories unless a later governed materialization package explicitly promotes them under schema, source-class, lineage, no-fabrication, and arming discipline.
