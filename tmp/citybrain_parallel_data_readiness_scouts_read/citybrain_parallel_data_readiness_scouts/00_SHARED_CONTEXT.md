# CityBrain — Parallel Data Readiness Scouts

Purpose: run bounded data-readiness scouts in parallel while the Web+Kit live surface implementation proceeds. These tracks do **not** add production features. They identify and land small, licensed, bounded datasets needed to make future demonstrability moments real.

Current certified spine: Mobility Access corridor. D8 demonstrated 12 committed moments, 10 demonstrable, 2 documented partial (M04 do-nothing baseline and M05 abstain/no-safe-option). NYC construction is parked post-D8. Do not build new hero substrate in these scouts.

Durable boundary: local/LAN/replay/review/query context only. No production/public API, no autonomous monitoring, no alerts, no dispatch, no routing/control, no enforcement, no legal/certified finding, no official ticket/case, no biometric/identity inference, and no automated action.

Metropolis/VSS rule: this sprint may establish data readiness and optional sample-output contracts only. It must not claim deployed Metropolis/VSS unless the actual stack runs locally and produces audited outputs from licensed video/data.
