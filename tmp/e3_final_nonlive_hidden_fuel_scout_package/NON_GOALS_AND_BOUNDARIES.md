# Non-goals and boundaries

This package must not:

- train a model
- create a forecast model
- create a ranker
- create a counterfactual learner
- create a case-memory learner
- create a product surface
- create a product ForecastPacket
- create cross-city learned transfer
- create dynamic investigation
- promote candidate inventory into training fuel
- fabricate outcomes
- convert snapshots into transition history
- count unverified exposure as R3 fuel
- infer operator dispositions from file names
- claim official action, dispatch, enforcement, legal/certified finding, or production readiness

This package is a final scout and classification pass.

It may recommend:
- closeout limitation rows
- Epoch 4 backlog rows
- one post-closeout materialization if explicitly approved later
- publication-home policy

It may not launch those follow-on tasks.
