# MAIN-CITYBRAIN-D8-VSS-LICENSED-CORPUS-ACQUISITION-R1

## Mission

Prepare the VSS/licensed video corpus acquisition lane for CityBrain D8 without downloading unauthorized media, using restricted datasets improperly, or making VSS readiness claims before the corpus, metadata, privacy labels, and expected-output oracle exist.

This is an acquisition/readiness package, not a perception implementation task.

## Starting context

Known current state:

- Metropolis/VSS lane is `DATA_READY` only in a narrow sense.
- GPU is present.
- Docker is missing.
- No audited licensed video corpus with camera metadata/oracle has been proven.
- Camera/video scout inventoried 91 local media refs.
- No new external media was downloaded.
- Singapore data.gov traffic image API probe returned `403`.
- LTA DataMall Traffic Images v2 remains API-key required.
- The task must avoid VSS/Metropolis/production/perception claims until corpus and oracle prerequisites are met.

## Required artifacts

1. `VSS_LICENSED_CORPUS_REQUIREMENTS.md`
   - Define minimum acceptable corpus requirements:
     - license/usage rights
     - source owner
     - jurisdiction/privacy context
     - camera metadata
     - scene/location description
     - timestamp metadata
     - frame rate/resolution
     - event categories
     - expected-output oracle
     - privacy/safety labeling
     - retention constraints
   - Must state that ordinary web video or unaudited public imagery is not acceptable for VSS readiness claims.

2. `VSS_CORPUS_CANDIDATE_LEDGER.json`
   - Candidate corpus/source list.
   - Include each candidate’s:
     - source name
     - source family
     - access status
     - license status
     - camera metadata status
     - oracle status
     - privacy review status
     - expected usefulness
     - blocker status
     - recommended next action
   - Include known blocked sources:
     - Singapore data.gov traffic images = `blocked_or_access_verification_required_403`
     - LTA DataMall Traffic Images v2 = `api_key_required`
   - Include local 91 media refs only as `local_inventory_refs_not_audited_corpus` unless proven otherwise.

3. `VSS_ORACLE_TEMPLATE.json`
   - Define expected-output oracle schema:
     - clip_id
     - camera_id
     - source_license_ref
     - privacy_label
     - event_windows
     - expected_objects
     - expected_zones
     - expected_candidate_events
     - negative_windows
     - reviewer_notes
     - acceptance_thresholds
   - Keep it model-agnostic.

4. `VSS_CAMERA_METADATA_TEMPLATE.json`
   - Define minimum camera metadata:
     - camera_id
     - site/location
     - coordinate/bbox if available
     - view orientation if available
     - field of view / scene zones
     - resolution/fps
     - timestamp handling
     - privacy mask requirements
     - source owner/license

5. `VSS_ACQUISITION_ACTION_PLAN.md`
   - Prioritized acquisition plan:
     - internal/local licensed sample first if available
     - municipal/partner-approved sample second
     - public datasets only if license and metadata support the test
     - synthetic Omniverse/Cosmos/DeepStream test clips only as synthetic, not real-world corpus
   - Include exact gating before any VSS readiness claim.

6. `VSS_READINESS_GATES.json`
   - Gates:
     - `licensed_corpus_available`
     - `camera_metadata_available`
     - `privacy_review_passed`
     - `oracle_available`
     - `runtime_stack_available`
     - `model_inference_smoke_passed`
     - `claim_boundary_passed`
   - Current expected state should remain not ready unless all above are proven.

7. `D8_VSS_LICENSED_CORPUS_ACQUISITION_DECISION.json`
   - Final decision:
     - task_id
     - status
     - candidates_classified
     - blockers
     - gates
     - hard_errors
     - limitations
     - next_recommended_task

8. `LOCAL_OPEN_INDEX.md`
   - Links to all created artifacts.

9. Hash/audit outputs:
   - `HASH_MANIFEST.json`
   - `hashes.sha256`

## Acceptance criteria

The task passes if:

- VSS corpus acquisition requirements are explicit and strict.
- Existing sources are classified without overclaiming.
- Blocked/API-key/captcha/form sources stay blocked until verified.
- Local media inventory is not treated as licensed VSS corpus unless audited.
- Oracle and camera metadata templates exist.
- A readiness gate file prevents premature VSS claim.
- No external unauthorized media is downloaded.
- Prior certified outputs are not mutated.
- JSON artifacts parse clean.
- Hashes verify.
