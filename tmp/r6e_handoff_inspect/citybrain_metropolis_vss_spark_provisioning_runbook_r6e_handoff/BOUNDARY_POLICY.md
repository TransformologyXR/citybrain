# BOUNDARY POLICY — R6E

Allowed:

- configuration discovery
- endpoint/command probe planning
- safe connectivity smoke
- model-generated narration classification
- human review requirement
- uncertainty and limitations

Forbidden:

- confirmed violation
- legal/certified finding
- identity or biometric inference
- official case/ticket/record
- dispatch/routing/control/enforcement
- alert as operational command
- automated action
- VSS as fact source
- VSS as sensor-inferred evidence
