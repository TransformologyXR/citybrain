# Non-goals and Boundaries

This package is a closeout package. It must not start new Epoch 3 work.

## Non-goals

- No new scouts.
- No new materializations.
- No new model training.
- No ranker experiment.
- No forecast model experiment beyond the already accepted offline component.
- No product forecast surface.
- No product ForecastPacket.
- No L4 case memory learner.
- No learned counterfactual model.
- No dynamic investigation.
- No cross-city learned transfer.
- No production deployment.
- No official action, dispatch, enforcement, legal, or certified claim.

## Allowed

- Closeout synthesis.
- Publication-home sweep of governance artifacts.
- Master ledger.
- LearnedComponentRegistry snapshot.
- Limitations and Epoch 4 backlog handoff.
- Hash and LF stabilization.
