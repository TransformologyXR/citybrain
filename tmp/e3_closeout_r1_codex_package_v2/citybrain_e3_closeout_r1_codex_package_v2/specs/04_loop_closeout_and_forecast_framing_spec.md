# Loop Closeout and Forecast Framing Spec

Loop closeout table must summarize L1-L4.

Forecast framing must say in one place:

- The offline forecast beat baseline on AP and Brier.
- The pipeline is validated.
- The specific R1 model is not deployable.
- Recall at fixed precision is weak.
- City divergence makes pooled product claims unsafe.
- Cross-city learned transfer remains parked.

Outputs:

- `E3_LOOP_CLOSEOUT_TABLE.json`
- `E3_FORECAST_RESULT_FRAMING_ROW.json`
- `E3_CITY_DIVERGENCE_WARNING_ROW.json`
