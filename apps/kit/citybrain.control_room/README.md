# CityBrain Kit Control Room

Maintained native Omniverse Kit extension source package for the Mobility Access spatial cockpit.

Extension path: `apps/kit/citybrain.control_room`

If an Omniverse Kit runtime is available, add this folder as an extension search path and enable `citybrain.control_room`.

R1 scope: native Kit panel UI, entity/evidence card on selection, citations, limitations, review-only / `not_executed` state, no-action boundary, and bounded overlay manager. WebRTC livestreaming is explicitly deferred to a separate lane.

Boundary: D8 Web + Kit live surface is local/LAN/replay/review/query context only. It projects the certified Mobility Access corridor into maintained Web and Kit source. It creates no production/public API claim, no autonomous monitoring, no alerts, no dispatch, no routing/control, no enforcement, no official ticket/case creation, no legal/certified finding, no certified citywide twin, and no automated action. Track D remains authoritative and execution_state = not_executed remains visible.
