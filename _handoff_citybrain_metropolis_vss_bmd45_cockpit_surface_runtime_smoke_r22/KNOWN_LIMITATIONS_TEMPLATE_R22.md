# Known Limitations R22

- This is a cockpit surface/runtime smoke, not a production UI release.
- It consumes R21 static fixtures; it does not rerun DeepStream or VSS.
- External media files are referenced, not packaged.
- No live RTSP/CCTV camera is configured.
- BMD-45 annotations are dataset annotations, not official truth.
- DeepStream detections are sensor-inferred candidates, not findings.
