# Boundary Policy

This task is a local/replay served-runtime integration smoke only.

Allowed:
- local fixture loading
- localhost-only runtime packet response simulation
- D6 static/local index generation
- synthetic/replay/donor-context labels
- no-action review wording

Not allowed:
- live monitoring claim
- production frontend claim
- public API claim
- dispatch, routing, enforcement, command, or control
- legal/certified/official Dubai truth
- human/person-level data
- raw provider payload packaging
- credential writing
- external provider calls
