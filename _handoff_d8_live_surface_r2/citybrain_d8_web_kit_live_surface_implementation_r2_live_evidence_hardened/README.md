# CityBrain D8 — Web + Kit Live Surface Implementation Pack

Run this after D8 Mobility-reanchored demonstrability handoff is green.

Start with `ENTRY_PROMPT.md`.

This R2-hardened pack promotes the Web UI and Omniverse Kit surface from generated/prototype artifacts into first-class local source surfaces over the certified Mobility Access corridor. It requires real Web local launch evidence before closeout/freeze, and honest Kit runtime status.

It is not a productionization sprint. It is a local/live demonstrator implementation sprint. Default web implementation is structured vanilla HTML/CSS/JS; do not add React/Vite/Next or internet package installs.
