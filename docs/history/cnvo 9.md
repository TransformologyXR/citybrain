## Current system summary

By the end of this thread, CityBrain has become a **review-only city intelligence cockpit**, not just a dashboard. The core product loop is:

```text id="citybrain-loop"
SOURCE RECORDS / EVENTS / MEDIA / SPATIAL SELECTIONS
→ IDENTITY
→ GRAPH
→ WATCH
→ SELECT
→ ASK
→ CHECK
→ BRIEF
→ RECALL / PLAN / SCHEDULE / SPATIAL / SIMULATE
→ HUMAN WORKFLOW STATE
→ GOVERNANCE TRACE
```

The uploaded product-mode docs frame the same split: operator-facing modes like WATCH, ASK, CHECK, BRIEF, RECALL, DIFF, PLAN, SCHEDULE, SPATIAL, WORKFLOW; system modes like IDENTITY, GRAPH, EVENT, PERCEPTION, SIMULATE, OPTIMIZE, GOVERN; and platform/commercial modes like QUALITY/MATURITY, FEDERATION, SYNTHETIC, and PERSONA.
