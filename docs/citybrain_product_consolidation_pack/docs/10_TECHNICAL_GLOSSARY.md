# Technical Glossary

## Glossary

| Term | Meaning |
|---|---|
| CER | Canonical Entity Registry: identity, aliases, source links, confidence, evidence and review state. |
| SEG | Semantic Entity Graph: relationship projection and traversal over the registry. |
| CHECK | Claimability engine: evidence sufficiency, contradiction, freshness, source class and boundary validation. |
| AuthorityEnvelope | Packet that states what can/cannot be claimed or acted on. |
| WatchItem | Candidate review prompt, not an alert or instruction. |
| Brief | Evidence-backed review packet for a human audience. |
| Candidate observation | Media/sensor/model output that may suggest something, but is not a finding. |
| Event Fabric | Append/replay/materialize/query layer for events and operational state. |
| Domain pack / cartridge | Reusable domain module: entity requirements, data sources, rules, tools, scenarios and UI rendering policy. |
| Local/replay | Non-production execution using controlled evidence, replay data or frozen bundles. |
| Frozen evidence | Inputs and outputs locked for reproducible review. |
| No-action boundary | The system stops before dispatch, enforcement, legal finding or official work order. |
| Product forecast surface | Operator-facing prediction UI; explicitly not available yet. |
