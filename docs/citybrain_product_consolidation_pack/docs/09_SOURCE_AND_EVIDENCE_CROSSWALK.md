# Source and Evidence Crosswalk

## Source crosswalk

This pack consolidates three kinds of source material:

1. Codex/export summaries and chronological ledgers.
2. Product/architecture docs such as CityBrain RTX Vision, Roadmap and Synthetic Data Stream.
3. Conversation summaries covering Omniverse, VSS/Metropolis, Epoch 3/4, product modes, gaps and parked work.

## Evidence interpretation

This is not a forensic repo audit. The generated docs use the uploaded summaries and exports as source material. Where a claim is safety-sensitive, the conservative interpretation is used: local/replay/frozen-evidence proof, not production live system.
