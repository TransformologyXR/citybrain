# BOUNDARY POLICY — R21

R21 is a review UI integration smoke, not an operational system.

Allowed:
- render review-only benchmark tiles
- show frame-review cards
- show source labels and limitations
- show external media references
- allow local review actions such as note, mark reviewed, hold, abstain, needs-source

Forbidden:
- official finding
- ticket/case creation
- dispatch/routing/control/enforcement
- legal/certified conclusion
- identity/biometric inference
- live CCTV monitoring claim
- treating model narration as fact
- treating sensor candidates as violations
