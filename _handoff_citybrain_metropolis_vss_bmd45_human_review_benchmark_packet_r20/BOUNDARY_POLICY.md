# BOUNDARY POLICY — R20

R20 is a review packet / UI fixture step.

Allowed:
- candidate review packet
- benchmark scorecard
- source-class labels
- comparison metrics
- false-positive review list
- missed-annotation review list
- external media refs
- human-review requirement

Not allowed:
- confirmed violation
- official case/ticket
- dispatch/control/action
- legal/certified finding
- identity or biometric inference
- live CCTV claim
- production monitoring claim
- VSS as fact source
