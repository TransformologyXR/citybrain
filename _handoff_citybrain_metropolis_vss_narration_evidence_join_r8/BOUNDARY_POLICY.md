# BOUNDARY POLICY — R8

The system may output:

- candidate observation
- candidate event
- model confidence
- frame/time/media reference
- source-class provenance
- model-generated narration sidecar
- uncertainty notes
- human-review packet

The system may not output:

- confirmed violation
- legal/certified finding
- identity or biometric inference
- official case/ticket
- dispatch/routing/control/enforcement
- alert as operational command
- automated action

VSS is not a sensor. It is a model-generated narrator/reader. It must remain distinct from DeepStream/Metropolis structured detections.
